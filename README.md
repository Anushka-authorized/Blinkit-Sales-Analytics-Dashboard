# 🟡 Blinkit Sales Analytics Dashboard

## 📊 Project Overview

The Blinkit Sales Analytics Dashboard is an interactive
business intelligence project designed to analyze retail
sales performance and outlet-level business metrics.

The dashboard provides insights into sales trends, item
categories, outlet characteristics, and average customer
ratings through interactive visualizations and filters.

## 🎯 Project Objectives

- Analyze total and average sales performance.
- Evaluate item category performance.
- Understand sales distribution across outlet tiers.
- Compare outlet sizes and outlet types.
- Analyze outlet establishment trends over time.
- Track average customer ratings.
- Enable interactive filtering for focused analysis.

## 📈 Key Performance Indicators

- Total Sales
- Average Sales
- Number of Items
- Average Rating

## 📊 Dashboard Features

- Interactive filter panel
- Sales performance KPI cards
- Outlet establishment trend analysis
- Fat content distribution
- Item type performance comparison
- Outlet size analysis
- Outlet location and tier analysis
- Outlet type performance table

## 🛠️ Tools & Technologies

- Data Visualization
- Business Intelligence
- Sales Analytics

## 💡 Key Insights

The dashboard enables users to explore sales patterns,
compare outlet performance, and identify differences
across product categories and outlet characteristics.
